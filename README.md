# Khushi Calibration & Testing Lab — Enhanced Website

A responsive, polished static website built with plain HTML, CSS and JavaScript.

## Included features
- Responsive desktop, tablet and mobile layouts
- Sticky navigation and accessible mobile menu
- Hero section with custom CSS measurement illustration
- About, service, industry, process, FAQ and contact sections
- Service search and category filters
- Expandable FAQ accordion
- Scroll reveal effects and back-to-top controls
- Enquiry form validation and copy-to-clipboard helper
- Email-app handoff after adding the verified laboratory email address
- SEO description and social sharing metadata
- Reduced-motion support and keyboard accessibility improvements

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in a browser.

## Important before publishing
This is a professional website template, not a verified company profile. Confirm every business detail with the laboratory before launch.

1. In `script.js`, replace `REPLACE-WITH-VERIFIED-EMAIL@example.com` with the laboratory's actual, verified email address.
2. Add a verified phone number, exact postal address, Google Maps link and working hours if the business provides them.
3. Confirm which calibration and testing services are actually offered; remove or update enquiry categories that do not apply.
4. Do not claim NABL accreditation, ISO certification, traceability, or any other certification unless the current certificate and approved scope have been checked.
5. Replace the CSS instrument illustration with genuine, approved laboratory, team and equipment photographs when available.
6. The enquiry form does not submit to a server. It prepares an email in the visitor's email app or copies the enquiry text. For automatic lead collection, connect a secure backend or form service and add spam protection and a privacy notice.
7. Test the site on real phones, tablets and desktop browsers before publishing.

## Files
- `index.html` — page structure and content
- `style.css` — design system, responsive layout and animations
- `script.js` — menu, filters, FAQ, scrolling and enquiry behaviour
